# IRC Client

Консольний клієнт для IRC-чатів, який розробляється в межах курсової роботи з дисципліни «ТРПЗ». На поточному етапі проєкт збирається через Maven, а під час запуску виводить `IRC Client`.

## Вимоги

- JDK 21 або новіший. Цільова версія компіляції — Java 21.
- Apache Maven. Команда `mvn -v` має виконуватися в терміналі.

## Збірка

У корені репозиторію виконай:

```powershell
mvn clean package
```

Maven скомпілює код, виконає тести й створить JAR-файл у каталозі `target`.

## Запуск

Після успішної збірки виконай із кореня репозиторію:

```powershell
java -cp target/classes ua.kpi.coursework.irc.Main
```

Очікуваний вивід:

```text
IRC Client
```
